✍️ Mensagem com Spintax

O que é Spintax?
É uma técnica antiban que cria variações da sua mensagem a cada envio. Use chaves {} e separe opções com a barra |.

Exemplo: {Olá|Oi|Saudações} {name}! Como {você está?|vão as coisas?}
O sistema vai sortear uma das opções em cada chave para cada contato.
